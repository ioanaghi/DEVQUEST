# Roadmap

## 0.1 — First day

- Native, offline macOS app with bundled runtime.
- Avatar, connected office rooms, NPC interactions, and collision-aware movement.
- Java boundary debugging, SQL filtering and JOIN investigation.
- Sample tests, separate review datasets, progressive hints, local saves.
- XP, achievement, desk personalization, journal, and training labs.

## Next: learning depth

- Package an appropriately isolated full Java runtime for desktop.
- Independent challenges to distinguish guided completion from mastery.
- Rich code editor, syntax diagnostics, and expanded curriculum content.
- More original sprite animation and sound.
- Developer ID signing/notarization and separate Intel/Apple Silicon releases.

## Later chapters

Developer foundations; Java fundamentals; OOP; SQL/databases; data structures; algorithms; backend engineering; professional engineering; system design; interview practice.

Each chapter needs its own story, conceptual lab, original practice problems, independent checks, and final project. Chapter cards alone do not constitute implemented curriculum.

## Beyond the local game

Optional accounts and sync, save migration, accessibility refinements, a cosmetic coin shop, cloud-backed isolated execution, and additional desktop platforms. Learning access should continue to reflect demonstrated skills; cosmetic spending must remain separate.

# Changelog

## 0.2.0 — An office to get lost in

The office now fills the screen, with a compact floating HUD and game overlays for pause, quests, map, journal, skills, and inventory. The Mac app starts in native full screen and remembers later window-mode choices. Escape opens and closes game menus without leaving full screen. Added keyboard shortcuts, a native Save & quit action, and a larger dark workstation overlay.

Rebuilt the office graphics with textured oak flooring, layered window light, detailed furniture, shaded and animated character sprites, depth sorting, ambient dust, server lights, coffee steam, and custom menu icons. Existing saves are retained.

## 0.1.0 — First Day

Initial first-day vertical slice: native macOS host, original office world, customizable developer, mentor story, Java boundary-debugging practice, real SQLite investigations, progressive handwritten hints, independent submission datasets, XP, desk rewards, achievement, journal, and local save import/export.

Developer tooling includes meaningful feature branches, automated runtime/progression/map checks, a separate Docker Java integration job, and downloadable macOS build artifacts. Later curriculum chapters are explicitly planned.
